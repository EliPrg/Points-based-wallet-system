# Points-based-wallet-system
Logical core of a loyalty-based program

Niveles completados: nivel 1 (base) y nivel 2 (intermedio). El nivel 3 (devoluciones de compra) no fue implementado.

1. El programa no utiliza dependencias externas, unicamente utiliza las que vienen por defecto en python, para ejecutar el problema basta con instalar la carpeta src, abrir dicha carpeta desde la terminal y aplicar el comando python junto al nombre del archivo main.py
2. Los datos se modelaron utilizando primero bajo el paradigma de la programación orientada a objetos para facilitar la organización de todos los datos manejados en el programa, siendo acompañado de tuplas, arreglos y diccionarios que facilitaron el almacenar la información dentro de la memoría
3. Entre las limitaciones principales esta lógicamente el no haber alcanzado el tercer nivel, la falta de un catalogo de objetos para comprar, el uso de alguna interfaz y algunas validaciones al momento de recibir los datos, también me gustaría pulir más mis métodos y validaciones con un poco más de tiempo
